# Legacy Asset Migration Policy

LIU BEIHE / 刘北河 maintains a separation between the current public artistic identity and pre-2026 materials created, credited, or documented under earlier names or contexts.

## Why this exists

A real historical asset should not be discarded simply because it predates the current identity. But it also should not be silently rewritten as if it had always belonged to the LIU BEIHE public chronology.

## Migration classes

### A — Directly migratable
The work/person linkage is documented, the chronology remains accurate, and public use will not create false credit, false institutional history, or identity confusion.

### B — Identity explanation required
The underlying asset appears real, but is credited to an earlier public name or identity. It can only move into the LIU BEIHE public record after an explicit, transparent identity-continuity decision.

### C — Internal only
Potentially useful evidence that is weak, irrelevant, independently unverified, or not appropriate to the current artistic biography.

### D — Do not use
Fabricated, unverifiable, misleading, materially inconsistent, or otherwise unsuitable for public claims.

## Public archive rule

The public archive does not automatically ingest old awards, education claims, screenings, exhibitions, or credits. Each item must preserve its original date, issuing institution, credited name, and evidence status.

Provisional creative metadata is never merged into verified biography records.
